# Bauchtagebuch – Android-App

Zeigt die Web-App (GitHub Pages) in einem eigenen Fenster und hält über das Garmin Connect IQ Mobile SDK
eine Bluetooth-Verbindung zur Uhr-App „Bauchtagebuch kcal“ – auch ohne Internet am Handy.

Gebaut wird per GitHub Actions (`.github/workflows/android.yml`); die fertige APK:
https://github.com/salamandercreator/bauchtagebuch/releases/download/android/bauchtagebuch.apk

Keine Schlüssel, URLs mit Zugang oder persönlichen Daten im Code – die trägt man in der App ein.
